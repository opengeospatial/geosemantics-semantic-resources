== Abstract

This OGC Community Standard defines the GeoSPARQL Geometry Datatype Registry, a curated set of RDF literal datatypes (`rdfs:Datatype`) and accompanying serialization properties maintained by the OGC GeoSPARQL Standards Working Group (SWG). These datatypes enable standardized representation of 2D, 3D, discrete global grid, and web-native geometry serializations within RDF and SPARQL ecosystems.

== Introduction

The OGC GeoSPARQL standard defines a vocabulary and query language for representing and querying geospatial data in the Resource Description Framework (RDF) and SPARQL. While core GeoSPARQL establishes foundational geometry serializations such as Well-Known Text (`geo:wktLiteral`) and Geography Markup Language (`geo:gmlLiteral`), modern geospatial workflows rely on a diverse ecosystem of domain-specific, web-native, and 3D geometry encodings.

This Community Standard documents the **GeoSPARQL Geometry Datatype Registry**, providing standardized Internationalized Resource Identifiers (IRIs), formal definitions, and metadata for representing diverse spatial formats directly within RDF graphs.

=== Registry Overview

The datatypes specified in this document extend GeoSPARQL interoperability across multiple geospatial communities without altering the core GeoSPARQL ontology:

* **2D and Vector Web Formats**: Encodings optimized for web APIs, lightweight exchange, and structured data, including GeoJSON, JSON-FG, GeoYAML, and GPX.
* **Binary and Discrete Spatial Representations**: Compact and grid-based serializations such as Well-Known Binary (WKB), Discrete Global Grid Systems (DGGS), and geocoded identifiers.
* **3D and Visualization Formats**: Geometry serializations supporting 3D scenes, meshes, and Earth-browsing applications, including KML, glTF, OBJ, PLY, and X3D.

=== Registry Structure

Each entry in the registry is maintained as a machine-readable Turtle (`.ttl`) resource in the OGC Geosemantics Semantic Resources repository. For every registered geometry format, this document specifies:

1. **Datatype Definition**: The canonical IRI, human-readable label, formal scope definition, and semantic metadata (`rdfs:Datatype` attributes).
2. **Accompanying Properties**: Associated RDF serialization properties (such as subproperties of `geo:hasSerialization`) that link `geo:Geometry` instances to literals typed with the corresponding datatype.

By establishing persistent, dereferenceable datatype IRIs and consistent property patterns, this registry enables data publishers, triple stores, and client applications to unambiguously declare, validate, and exchange specialized geometry literals in Linked Data environments.
